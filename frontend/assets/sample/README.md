# Sample Photos for Carbon Footprint Calculator

Place sample waste item photos here for local testing and demonstration.

## Recommended sample files:
1. `example-1.jpg` - Clean aluminium beverage can (metal, ~15 g)
2. `example-2.jpg` - Transparent PET drink bottle (plastic_low, ~25 g)
3. `example-3.jpg` - Corrugated cardboard scrap or A4 paper sheet (paper, ~5-30 g)
4. `example-4.jpg` - Apple core or fruit peels (organic, ~80 g)
5. `example-5.jpg` - Wood offcut or chopstick (wood, ~10 g)

The "Try an example" button looks for `assets/sample/example-1.jpg`. If this file is absent, the application gracefully alerts the user with guidance to select or drop an image.
